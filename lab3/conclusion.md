# Выводы

Генеральные распределения: U(0, 1) и Exp(λ = 1). СКО оценок считалось по N = 10³ выборкам для каждого n (таблицы — в `sd.md`).

## Равномерное распределение

- **Метод моментов** (`a*, b* = m₁ ∓ √(3(m₂ − m₁²))`) состоятелен: оценки сходятся к 0 и 1, СКО убывает как `1/√n` (≈ 0.037 при n = 100, ≈ 0.0035 при n = 10⁴). При малых n оценки смещены «внутрь» отрезка (a* > 0, b* < 1), смещение быстро исчезает.
- **ОММ с единичными весами (W = I)** почти не помогает. Старшие моменты `x^k` определяются в основном значениями около правой границы, поэтому σ(b*) немного падает (0.0026 вместо 0.0036 при K = 7, n = 10⁴), а σ(a*) растёт (0.0048 вместо 0.0035).
- **Предложенные веса — W = S⁻¹**, где S — ковариационная матрица функций `x, x², …, x^K`, вычисленная по формулам равномерного распределения в точке оценки метода моментов (двухшаговый ОММ). Это оптимальные веса: асимптотическая дисперсия `(Gᵀ S⁻¹ G)⁻¹` минимальна среди всех W и не возрастает при добавлении моментов. На практике СКО обеих границ снижается с ростом K: при n = 10⁴ — 0.0035 (МM), 0.0027 (K = 3), 0.0017 (K = 5), 0.0013 (K = 7), т.е. в ≈ 2.7 раза меньше классического метода моментов. Скорость по-прежнему `1/√n`, меняется только константа.
- Для сравнения: ОМП (min/max выборки) для равномерного распределения имеет СКО порядка `1/n`, поэтому любые моментные оценки здесь асимптотически хуже — моменты не используют информацию о том, что плотность обрывается на границах.

## Экспоненциальное распределение

- **Метод моментов** `λ* = 1/x̄` состоятелен, СКО ≈ λ/√n (0.103 при n = 100, 0.010 при n = 10⁴) — это граница Рао–Крамера, т.е. оценка асимптотически эффективна (она совпадает с ОМП). При малых n есть положительное смещение (≈ 0.12 при n = 10), так как `E[1/x̄] = nλ/(n − 1)`.
- **ОММ с W = I** заметно хуже, и тем хуже, чем больше K: моменты `E[X^k] = k!/λ^k` имеют огромную дисперсию (тяжёлые хвосты `x^7`), и без весов они доминируют в функционале. При n = 10⁴ σ(λ\*) = 0.014 (K = 3), 0.030 (K = 5), 0.054 (K = 7) против 0.010 у MM; появляется и большое смещение вверх.
- **ОММ с W = S⁻¹** даёт в точности ту же оценку, что и метод моментов, при любом K. Причина: x̄ — достаточная статистика, функция вклада `∂ ln f/∂λ = 1/λ − x` линейна по x, и оптимальная комбинация моментных условий вырождается в одно условие на первый момент. Снизить дисперсию по сравнению с классическим методом моментов здесь нельзя — он уже достигает границы Рао–Крамера.

## Общий вывод

Добавление моментов само по себе дисперсию не снижает: при неудачных (единичных) весах старшие моменты с большой дисперсией ухудшают оценку. Оптимальные веса `W = S⁻¹` никогда не хуже метода моментов; выигрыш тем больше, чем больше информации о параметре содержится в старших моментах (равномерное распределение), и равен нулю, если первый момент уже является достаточной статистикой (экспоненциальное распределение).
